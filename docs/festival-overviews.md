# Editorial festival overviews

Edit `lib/catalog/festival-overviews.ts` in a reviewed change to add, revise
or remove an overview. Each entry identifies a canonical festival, edition
and organizer-described place, with concise original prose in EN, DE and RU.
Use the organizer's explicit published description of the matching edition.
Record the public HTTPS source and the editorial check date. Verify all
localized versions against the same facts.

Do not treat stage descriptions as a timetable, ticket information as stock,
or a previous edition's description as evidence for a later edition. If the
edition, venue, or format changes, recheck the entry rather than carrying its
copy forward. The site omits an overview when the exact catalogue edition and
place no longer match. The check date is only for that overview, not the
festival's overall freshness or ticket availability.
